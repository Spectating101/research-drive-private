3 · Rules the set encodes

Truth contract

  • Canvas is durable truth. Ask enters via the rail with the object attached — never inside evidence or execution cards.
  • Selection stays in the ranked results; the centre selection never disappears.
  • A request exists before a route is resolved. Route, method, execution, archive, registration and readiness are separate gates.
  • Completed work returns to Needs you only for a researcher-owned decision.
  • Accepting a method binds the method. It does not create a Library asset.
  • A completed worker is not registered until archive and registry both confirm.
  • Unknowns are named, never omitted. Not reported is a valid value.
  • No numbered process strip before acceptance. The lifecycle strip is permitted only once a construction is accepted.
  • Next valid action is an exact supported action — never a fabricated executable promise.
  • Every readiness number carries its projection: declared / reconciled / returned-window / observed-materialized.
